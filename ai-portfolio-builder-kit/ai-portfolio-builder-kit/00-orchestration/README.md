# 00 · Orchestration

This folder tells the building agent **how to operate**. Read all three files before touching any code.

| File | Read when |
|---|---|
| `agent-playbook.md` | First. Your operating manual for the whole build. |
| `principles.md` | First. The non-negotiable do's and don'ts. |
| `build-phases.md` | First. The ordered plan with gates between phases. |

The mental model: this kit is your **senior teammate who already built this once**. It hands you proven patterns and warns you about the exact potholes. Follow the phases, respect the gates, and check the pitfalls folder whenever something feels fragile.
