# 08 · Agent Tooling

How an AI agent should use its own capabilities — skills, subagents, and validation habits — while building the portfolio.

| File | Purpose |
|---|---|
| `skills-overview.md` | Which reusable skills help, and at which phase |
| `subagents.md` | When to parallelize with subagents/forks, and when not to |
| `component-change-validation.md` | The ASCII-first protocol for risky component edits |
| `skills/` | Clean, reusable skill templates (anonymized) |

These are written for agents that support skills and subagents (e.g. Claude Code). If your agent doesn't, treat them as **checklists and workflows** you run manually — the value is in the process, not the automation.
