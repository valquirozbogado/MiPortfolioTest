# 09 · Quality

The **Phase 5** audits. Run them before shipping; re-run after significant changes.

| File | Focus |
|---|---|
| `accessibility.md` | Keyboard, ARIA, focus, contrast, motion |
| `performance.md` | Bundle, images, lazy-loading, fonts |
| `seo-and-metadata.md` | Titles, descriptions, OG, structured data — anonymized |
| `design-review.md` | A self-review rubric to catch what automated checks miss |

A portfolio is judged on polish. These four files are the difference between "looks like a template" and "looks considered."
